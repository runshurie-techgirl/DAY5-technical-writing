# Day 5 Assignment: Technical Writing Lab

This repository contains my Day 5 technical writing lab submission. The lab asked me to write two kinds of technical documents under time limits: a user manual procedure and an API reference entry.

## Exercise A: User Manual Procedure

A beginner-friendly guide to creating and activating a Python virtual environment and installing a package on Windows.

- **Audience:** first-semester computing students with basic computer skills and no experience with the Command Prompt or Python tools
- **Includes:** prerequisites, key terms, 16 numbered steps (one action per step, each with an expected result), two screenshot descriptions, and a troubleshooting note
- **Troubleshooting covered:** the `'python' is not recognized` error, the most common beginner problem

## Exercise B: API Reference Entry

A complete reference entry for an endpoint that creates a new task in a project management application.

- Endpoint: `POST /api/v1/projects/{project_id}/tasks`
- **Includes:** a plain-language description, authentication and request headers, path, query, and body parameters (name, type, required or optional, description), all HTTP response codes with when each occurs, an example request in JSON and curl, and example success and error responses
